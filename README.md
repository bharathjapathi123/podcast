# 🎙️ Podcasts Website

## 📌 Project Overview

The **Podcasts Website** is a static web project designed to display different podcast categories and their episodes in an organized and visually appealing layout.

The website provides a main Podcasts page where users can explore different podcast categories such as **Puri Jagannadh, TEDx Talks, Sadhguru, and On Purpose**. Each category contains information about the number of episodes available.
When a user selects a podcast category, the website displays a dedicated section containing the podcast title, description, episode names, descriptions, and episode durations. A **Back** button allows users to return to the main Podcasts page.

## ✨ Features

* Displays multiple podcast categories.
* Shows the number of episodes for each podcast.
* Provides individual podcast sections.
* Displays episode titles, descriptions, and durations.
* Includes interactive navigation between podcast sections.
* Provides a Back button to return to the main page.
* Uses responsive Bootstrap layout utilities.
* Uses custom CSS for colors, typography, spacing, and card styling.
* Uses images for podcast categories and episodes.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the website.
* **CSS3** – Used for custom styling, colors, spacing, fonts, and layouts.
* **Bootstrap 4.5.2** – Used for responsive layouts and utility classes such as flexbox.
* **JavaScript** – Used for section navigation through click events.

## 🎨 Design

The website uses a podcast-themed background image for the main section with a prominent **Podcasts** heading. The podcast categories are arranged using Bootstrap flexbox utilities.

Each podcast detail section uses a dark blue header area containing the podcast image, title, and description. Episode information is displayed below the header in a structured horizontal layout.

## 🎧 Podcast Categories

The website includes four main podcast categories:

1. **Puri Jagannadh**
2. **TEDx Talks**
3. **Sadhguru**
4. **On Purpose**

Each category provides multiple episodes with their respective descriptions and durations.

## 🧭 Navigation

Users can click on a podcast category to open its corresponding section. The HTML uses click events such as `display('section1')`, `display('section2')`, and so on to navigate between sections.

A **Back** button is provided at the bottom of each podcast section to return to the main Podcasts page.

## 🚀 How to Run

1. Download or clone the project.
2. Keep `index.html` and `podcast.css` in the same folder.
3. Open `index.html` in a web browser.
4. Select any podcast category to explore its episodes.
